# System Admin Guide

## What system admins can do
View all sponsorship requests and maintain sponsorship types.

## View all requests
1. Go to Requests.
2. Open any record to see details and audit history.

Expected result: All workflow records are visible.

## Manage sponsorship types
1. Go to Sponsorship Types.
2. Add a name and description.
3. Select Create type.
4. Use Edit to update active status or details.

Expected result: Active types appear in request creation forms.

## Common mistakes or warnings
Types already used by requests are deactivated instead of removed to preserve history.
