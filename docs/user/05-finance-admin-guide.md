# Finance Admin Guide

## What finance admins can do
Review requests approved by managers, final approve, or reject with finance remarks.

## Final approve
1. Go to Requests.
2. Open a Pending Finance Review request.
3. Add optional remarks.
4. Select Final approve.

Expected result: Status changes to Approved.

## Reject
1. Open a Pending Finance Review request.
2. Enter rejection remarks.
3. Select Finance reject.

Expected result: Status changes to Rejected.

## Common mistakes or warnings
Finance admins only act after manager approval. Rejection remarks are required.
