# Status Explanation

Draft means the requestor has saved the request but not submitted it.
Pending Manager Approval means the request is waiting for manager decision.
Pending Finance Review means the manager approved it and finance must decide.
Approved means finance gave final approval.
Rejected means either manager or finance rejected the request.
Cancelled means the requestor cancelled before approval.

## Workflow path
Draft → Pending Manager Approval → Pending Finance Review → Approved.

## Alternate endings
Pending Manager Approval can become Rejected or Cancelled. Pending Finance Review can become Rejected.
