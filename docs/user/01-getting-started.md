# Getting Started

SRAWS is a sponsorship request approval system for creating, reviewing, approving, rejecting, and auditing sponsorship requests.

## Roles
Requestor creates and tracks requests. Manager performs first approval. FinanceAdmin performs final approval. SystemAdmin views all records and manages sponsorship types.

## First steps
1. Open the frontend URL.
2. Sign in using one of the demo accounts.
3. Use the left navigation to access the pages available to your role.
4. Use request details to view status, decision actions, and workflow history.

## Expected result
You only see pages and actions that match your role.
