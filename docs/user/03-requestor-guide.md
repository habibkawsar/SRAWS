# Requestor Guide

## What requestors can do
Create sponsorship requests, save drafts, submit for approval, view own requests, track status, and cancel before approval.

## Create and save draft
1. Go to Create Request.
2. Complete the required fields.
3. Select Save draft.

Expected result: The request is saved as Draft and opens on the detail page.

## Submit request
1. Open a Draft request.
2. Select Submit.

Expected result: Status changes to Pending Manager Approval.

## View own requests
1. Go to Requests.

Expected result: You see only your own requests.

## Cancel request
1. Open a Draft or Pending Manager Approval request.
2. Add optional remarks.
3. Select Cancel.

Expected result: Status changes to Cancelled.

## Common mistakes or warnings
Rejected requests cannot be resubmitted in this implementation. Approved or finance-pending requests cannot be cancelled by requestors.
