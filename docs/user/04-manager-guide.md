# Manager Guide

## What managers can do
View requests waiting for manager approval, approve them for finance review, or reject them with remarks.

## Approve
1. Go to Requests.
2. Open a Pending Manager Approval request.
3. Add optional remarks.
4. Select Manager approve.

Expected result: Status changes to Pending Finance Review.

## Reject
1. Open a Pending Manager Approval request.
2. Enter rejection remarks.
3. Select Manager reject.

Expected result: Status changes to Rejected.

## Common mistakes or warnings
Rejection remarks are required. Managers cannot approve finance-pending requests.
