# Login Guide

## What this feature does
Lets users securely access the system with email and password.

## Who can use it
All roles.

## Steps
1. Open the login page.
2. Enter your email.
3. Enter your password.
4. Select Login.

## Expected result
You arrive at your role-specific dashboard.

## Common mistakes or warnings
Use `Password123!` for demo accounts. If login fails, check that the backend API is running and `VITE_API_BASE_URL` points to it.

## Screens/pages involved
Login page and dashboard.
